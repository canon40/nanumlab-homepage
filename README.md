# 나눔랩 홈페이지 v2 (TypeScript)

React + Vite + TypeScript + Tailwind CSS + shadcn/ui 스타일 컴포넌트 기반의 나눔랩 AI·ICT 기업 홈페이지 **1차 버전**입니다.

> 기존 JavaScript 버전(`nanumlab homepage`)과 별도 프로젝트입니다.

## 실행 방법

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## 프로젝트 위치

- **v2 (이 프로젝트):** `d:\@code\nanumlab-homepage-v2`
- **v1 (기존):** `d:\@code\nanumlab homepage`
